HUSSEIN BADR ENGLISH — MODERN WEBSITE PACKAGE
================================================

هذه نسخة تصميم وتطوير مستقلة، وليست نسخة منشورة تلقائيًا على GitHub Pages.

الملفات الرئيسية:
- index.html: الصفحة الرئيسية
- paths.html: المسارات A1–C1
- lessons.html: مكتبة الدروس مع البحث والتصفية
- placement-test.html: اختبار مستوى تدريبي قصير
- flashcards.html: بطاقات مفردات تفاعلية
- dashboard.html: لوحة التقدم والتصدير/الاستيراد
- study-plan.html: خطة دراسة أسبوعية
- practice.html: تمارين عملية
- resources.html: موارد وروابط تعليمية
- about.html, contact.html, privacy.html, faq.html: صفحات معلومات
- 404.html: صفحة خطأ
- assets/css/style.css: التصميم العام المتجاوب
- assets/js/app.js: وظائف التفاعل والتقدم المحلي

طريقة الاستخدام:
1. احتفظ بنسخة احتياطية من الموقع القديم قبل استبدال أي ملف.
2. ارفع محتويات هذا المجلد إلى جذر مستودع GitHub Pages الخاص بالموقع.
3. حافظ على مجلد assets كما هو؛ يجب أن يبقى:
   assets/css/style.css
   assets/js/app.js
4. اختبر الموقع على الهاتف والتابلت بعد النشر.

مهم:
- هذا الموقع ثابت (HTML/CSS/JavaScript)، ولا يحتوي على خادم خلفي أو قاعدة بيانات.
- تقدم التعلم محفوظ في localStorage على الجهاز والمتصفح الحالي.
- اختبار المستوى تعليمي إرشادي وليس تقييمًا معياريًا.
- نموذج التواصل يفتح تطبيق البريد ولا يرسل الرسالة إلى خادم الموقع.
- قد تُحمّل الخطوط من Google Fonts عند توفر الإنترنت.
- لا تُرفع هذه النسخة إلى الموقع المنشور تلقائيًا بمجرد تنزيلها.
